Como testar na Unity

  1. Projeto D:/Dev/Personal/My_games/Tech-Guy. Tools → Tech Guy → RUN-EXP-04 → Revisão → Próxima incursão seed63, fora de Play. Assistência de recompensas desligada. Use o portal normal do Nexus.
  2. Primeiro combate63: dupla e cobertura no sorteio legítimo, junto de famílias antigas. Para sala inicial aberta: Tools → Tech Guy → RUN-EXP-03 → Próxima incursão com seed 0. Não há garantia dessa sequência em toda run.
  3. Contorne as massas, quebre LOS e retorne à linha de tiro. Observe a pressão melee e a retaguarda. Teste as três armas, skills, especial e dash conforme seus bindings atuais.
  4. Abra o laboratório de recompensas pelo mesmo menu, entre em Play e alterne Original/A/B/C e armas. Selecionar não concede; confirmar concede somente ao inventário temporário do laboratório. Sair de Play descarta a revisão.
  5. Para ofertas reais de uma run: menu Síntese C temporária na run atual. Uma confirmação nesse contexto consome o ticket real. Restaurar recompensa publicada remove a prévia. Nenhuma cena salva instala C automaticamente.
  6. Menus Salas antes/com polimento comparam somente apresentação durante Play; não alteram colisões nem saves.
