# Decisões (ADRs)

ADR registra escolha **durável**, seu contexto, alternativas e consequências. Não usar para bugs ou status de testes. A decisão pode estar `ACEITA`, `PROPOSTA` ou `SUPERADA`. Não mudar uma ADR aceita sem criar uma sucessora que indique o motivo.

Neste pacote, há registros de direções explicitamente discutidas e suas limitações. **Os detalhes arquiteturais adicionais continuam sujeitos a inspeção do repositório.**

- ADR-0001: papéis de referências e HUD.
- ADR-0002: reação contextual, não knockback universal.
- ADR-0003: identidade das três armas.
- ADR-0004: gates para conteúdo e validação de boons.
- ADR-0005: captura visual no ciclo de IA (proposta operacional, não feature implementada).
