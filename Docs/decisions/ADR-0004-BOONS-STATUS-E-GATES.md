# ADR-0004 — Não confundir código implementado com boon aprovado

- **Status:** ACEITA (critério de processo)
- **Contexto:** lotes de boons D/E/F foram relatados como compilados por CLI sem execução de testes Unity por falta de instância MCP; Mythics permaneceram desabilitados.
- **Decisão:** para habilitar/escalar conteúdo é preciso saber identidade/catalogação/compatibilidade, executor real, persistência/oferta, custo e proc budget, execução Unity, apresentação visual e aceite humano de diversão. Candidatos sem gates permanecem desabilitados.
- **Consequência:** docs de expansão podem conter backlog não implementado; um card pronto no catálogo não equivale a feature jogável.
- **Não decidido:** limites numéricos finais ou quais propostas pendentes serão escolhidas.
